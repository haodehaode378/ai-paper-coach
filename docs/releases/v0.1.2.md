# AI Paper Coach v0.1.2

发布日期：2026-05-28

## 版本概览
`v0.1.2` 是一次稳定性与发布卫生更新，重点修复测试契约漂移、后端弃用警告和版本标识不一致问题。

## 修复与改进
- 修复 PDF 上传接口测试：测试现在生成真实可解析 PDF，继续覆盖后端严格 PDF 校验逻辑。
- 后端生命周期改为 FastAPI `lifespan`，替代已弃用的 `on_event` startup/shutdown 写法。
- 修复 Pydantic `model_slot` 保护命名空间警告。
- 时间戳生成改为 timezone-aware UTC 写法，避免 `datetime.utcnow()` 弃用警告。
- 同步后端 API 与前端包版本号到 `0.1.2`。

## 验证
- 后端：`python -m pytest -q`，16 passed。
- 前端：`npm run build`，构建通过。
- 编码：`check-mojibake --root E:\ai-paper-coach`，未发现本次改动引入的乱码；报告中的命中为运行历史/正常中文文本的启发式提示。

## 已知问题
- 前端构建仍提示部分 chunk 超过 500 kB，主要来自 PDF worker 和主 bundle，后续可通过动态导入或手动分包优化。
- 根目录存在一个未跟踪的空壳 `package-lock.json`，本次未纳入发布提交。
